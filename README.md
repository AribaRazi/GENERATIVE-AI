## 🧪 Experiments

The `RUNNABLES` folder contains smaller experiments for understanding concepts such as:

* **Tool Calling** — connecting LLMs with Python functions/tools
* **Agents** — exploring AI agents and decision-making
* **Sequential Runnables** — chaining multiple operations
* **Parallel Runnables** — running operations in parallel
* **News Summarization** — using LLMs for summarization
